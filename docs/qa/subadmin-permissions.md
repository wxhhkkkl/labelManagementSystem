# 分公司管理员权限

分公司管理员仅显示工位管理、员工管理、码池查询、码补打、补打明细、打印明细六个目录。登录后的默认页为工位管理；手动打开其他后台网址会返回工位管理。总部管理员菜单保持完整。

工位管理仅限账号所属企业，可新建、修改、停用和解绑本公司工位。页面使用登录用户的公司信息，不调用总部组织管理接口。

码查询、补打、打印明细与导出均按所属公司校验；补打明细在 SQL 限量之前过滤所属公司，且不返回作废记录。作废、码追溯、组织树、产品管理、模板管理、导入、分配、看板和操作日志接口仅总部可访问。非总部账号没有企业归属时拒绝查询，避免因空公司条件扩大数据范围。

员工管理允许分公司管理员添加、修改和停用本公司操作员，列表只返回本公司操作员。新建表单固定角色为操作员、企业为当前公司，不允许创建管理员、操作管理员或操作其他企业员工。

产品筛选改用只读 `/products/options` 接口，非总部用户仅获取本公司码涉及的产品基本信息，不返回总部产品统计或模板绑定信息。此接口用于码查询、打印明细和工位打印的产品下拉框。

验证覆盖受限接口拒绝、本公司数据范围、他公司补打拒绝、工位管理边界、只显示允许目录、禁用页面直接访问跳转以及补打页面隐藏作废入口。
