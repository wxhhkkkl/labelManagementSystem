## SC-004：工位操作员从登录到产出第一张标签 ≤60 秒

**状态**：❌ **未执行** —— 需要真实工位软件与打印机。

### 测量规程

计时从"操作员在工位软件输入账号密码"开始，到"第一张标签从打印机出来"结束。
中间包含：登录 → 选产品 → 选数量 → 发起打印 → 出纸。

| 阶段 | 计时点 | 实测 |
|------|--------|------|
| 登录 | 点下"登录" → 进入打印页 | ______ 秒 |
| 选码 | 选产品 → 可打印码列表出现 | ______ 秒 |
| 发起 | 点"打印" → 页面显示"已出纸" | ______ 秒 |
| **合计** | | ______ 秒 |

**建议重复 3 次取均值**，首次冷启动通常最慢。

**已知会拖慢的环节**：
- 首次打开软件时的打印服务启动
- 打印机冷启动预热（热敏机尤其明显）
- 若 60 秒吃紧，优先看"登录"环节——它包含一次服务端往返

## SC-006：打印记录 100% 可追溯到操作员 + 工位 + 打印机

**状态**：✅ **已自动验证**。

| 断言 | 测试 |
|------|------|
| 每次打印生成记录，含全部字段 | `test_anti_duplicate_print.py::TestPrintRecordIsWritten` |
| 输出记录带操作员与工位 | `test_print_confirm.py` |
| 超时回退的记录归到发起打印的操作员 | `test_lock_timeout.py::TestTimeoutLeavesAnAuditTrail` |
| 500 码批量打印一条不漏 | `test_batch_print_perf.py::test_every_code_gets_a_print_log` |

**抽样核对方式**（联调环境可再人工抽查）：

```sql
-- 三字段非空的记录占比，应为 100%
SELECT
  COUNT(*) AS total,
  SUM(operator_id IS NOT NULL AND workstation_id IS NOT NULL AND printer_name <> '') AS traceable
FROM print_log;
```
