# 图文使用说明

入口：管理后台左侧「帮助中心 → 使用说明」、右上角「使用说明」，路由 `/help`。总部管理员和分公司管理员均可访问，登录及其他业务权限保持原有规则。

内容包括 23 个章节：入门与角色、网页端的基础设置及码管理、打印端的登录绑定及打印流程、常见问题。共 29 张当前界面截图；同一截图可在不同章节复用。截图均使用演示账号、产品、公司及码值，不使用生产数据。

- 内容：`admin-web/src/content/userManual.ts`
- 页面：`admin-web/src/views/help/UserManualView.vue`
- 截图：`admin-web/public/manual/`
- 交互检查：`admin-web/tests/e2e/user-manual.spec.ts`

## 更新截图

在项目根目录执行 `node scripts/capture-user-manual.cjs`，运行前安装 `admin-web` 依赖、确保 Microsoft Edge 可用，并启动本地管理端 5173 和打印端 5174。

脚本通过 Playwright 打开真实页面，拦截全部业务 API 和本地打印请求，注入演示数据。不会创建真实公司、员工或补打任务，也不会让打印机出纸。输出覆盖上述截图目录，截图右下角均带演示标记。页面变化后应同步核对文字步骤及重新截图。

## 本次验证

- 管理后台生产构建通过，128 项单元测试通过。
- 界面测试覆盖总部入口、23 个章节、分类、图片放大和关闭、全部截图资源，以及分公司访问和其他目录仍隐藏。
- 检查桌面和 390 像素宽度显示，无页面横向溢出。
- 教程明确：补打自动领取后需手动点击打印；回收要求整单没有已打印或打印中的码；修改模板不改变已有分配单；预览不生成首次打印日期或流水号。

页面可以调用浏览器打印或保存 PDF，会先加载当前筛选章节中的图片。若要打印完整说明，选择「全部」。
