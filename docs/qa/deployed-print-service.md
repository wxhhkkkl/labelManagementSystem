# 打印端连接部署服务

工位打印端统一使用 `https://lms.yuwangchenfa.com`，地址来源为 `print-client/src/serviceConfig.ts`。

开发服务器代理和 Electron 主进程共享该配置。Electron 渲染层的业务请求通过 preload 提供的受限 IPC 发送，主进程使用 `net.fetch` 访问 HTTPS 服务，因此安装版从 `file://` 打开也可以访问。服务器当前未启用浏览器跨域预检，不需要为了运行打印端关闭浏览器安全限制。

请求仅允许固定服务的 `/api/v1/` 路径和业务请求头；阻止目录逃逸、其他主机和重定向，保留令牌、机器标识、错误响应与绑定失效处理，并设置 30 秒超时。本地 17650 打印服务保持原有功能。

2026-10-18 验证：

- 部署网站 HTTPS 可访问。
- 真实管理员账号登录、当前用户、产品选项和工位列表均返回 200，未携带令牌访问当前用户返回 401。
- 使用 Electron 实际加载构建后的 `file://` 页面，通过真实 preload 与 IPC 完成上述远程登录及只读接口检查。
- 未创建分配、工位绑定或业务打印任务，未实际出纸。

工位绑定和日常打印仍需要使用关联到对应公司的操作员账号。总部账号的接口连接检查不代表操作员的生产打印流程已完整测试。
