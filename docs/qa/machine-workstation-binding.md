# 工位机器绑定

工位与打印端机器绑定，账号仅用于认证和识别企业，不要求先建立工位—操作员关系。

打印端在应用本地数据目录保存机器 UUID。登录后先查询服务端该机器的绑定：存在且属于登录企业时恢复；不存在时列出该企业启用且尚未绑定机器的工位。只有一个候选时默认选中，点击绑定完成登记。换用同企业账号不会改变机器绑定；退出登录不释放工位。

服务端用企业锁和工位行锁串行处理绑定，并以唯一机器标识约束防止一机多工位。已绑定工位的打印、心跳、任务及打印机设置接口校验机器标识和账号企业。其他企业账号不能沿用本机绑定。

迁移 0006 只新增机器标识列与唯一约束。历史 bound_at 不作为机器绑定证据，旧客户端的本地工位 ID 需经过新绑定流程确认。未升级的客户端没有机器标识，不能调用新绑定接口。

后台工位列表显示已绑定 / 未绑定。已绑定工位不会因为离线而被列为可绑定，避免另一台机器抢占。验证覆盖企业候选列表、无操作员关联、重复绑定、机器恢复、企业隔离、机器请求校验及打印端登录 / 恢复 / 退出流程。

总部管理员可解绑任意工位，子公司管理员仅可解绑本企业工位，操作员无解绑权限。工位管理点击“解绑机器”并确认后，清除机器标识、打印机和在线心跳，记录解绑审计。历史绑定时间保留用于拒绝旧客户端继续操作。存在预占打印或已领取补打任务时拒绝解绑；待处理任务保留给后续绑定该工位的机器。

原机器下一次心跳或业务请求收到绑定失效响应时，清除本地工位和打印机选择，停止原页面轮询并返回企业空闲工位选择页面。恢复后绑定再次由服务端校验。

打印端每次启动都要求操作员重新登录，不沿用上次账户会话；登录后由机器标识恢复工位，不需要重新绑定。顶部显示当前操作员姓名和账号、企业名称、工位名称。打印端取消手动打印机配置，读取并使用 Windows 默认打印机；未设置默认打印机或打印服务不可用时禁止预占打印。扫码定位仅用于切换到扫描码的产品，不自动发起打印。
