## 范围

FR-075 只要求 **Windows 10 下的 Chrome / Edge 主流版本**。
不要求 Firefox、Safari，也不要求移动端。

建议覆盖的版本（执行时以当时的最新稳定版为准）：

| 浏览器 | 版本 | 通道 |
|--------|------|------|
| Chrome | 最新稳定版 | 正式 |
| Chrome | 上一个稳定版 | 正式 |
| Edge | 最新稳定版 | 正式 |
| Edge | 上一个稳定版 | 正式 |

Chrome 与 Edge 同为 Chromium 内核，二者差异通常很小；
真正需要盯的是**版本回退时的兼容性**（用户机器上的浏览器往往不是最新的）。

## 验证清单

每个浏览器版本都要走一遍。**任一项失败即记为该版本不通过**。

| # | 检查项 | 判定标准 | Chrome | Edge |
|---|--------|----------|--------|------|
| 1 | 登录 | 输入账号密码后可进入，无报错 | ☐ | ☐ |
| 2 | 组织树 | 公司与工位层级正确展开 | ☐ | ☐ |
| 3 | 产品管理 | 列表、搜索、新建弹窗均可操作 | ☐ | ☐ |
| 4 | 码导入 | 上传两个文件后进度条推进至终态 | ☐ | ☐ |
| 5 | 模板编辑器 | **元素可拖拽**，坐标随拖动变化 | ☐ | ☐ |
| 6 | 模板预览 | 版面与编辑区一致，无元素错位 | ☐ | ☐ |
| 7 | 码分配 | 新建分配有二次确认，成功后有单号提示 | ☐ | ☐ |
| 8 | 看板 | 四态分布数值正常显示，条形比例正确 | ☐ | ☐ |
| 9 | 打印明细 | 多维筛选生效，导出能下载 xlsx | ☐ | ☐ |

**第 5 项要特别关注**：模板编辑器的拖拽用了 Pointer Events，
不同浏览器对 `setPointerCapture` 的行为有细微差别，是本次最可能需要适配的地方。

**第 12 项**：xlsx 由服务端生成（openpyxl），CSV 导出带 UTF-8 BOM——
前者不依赖浏览器，后者依赖 BOM 被正确识别。
