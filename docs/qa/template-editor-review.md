# 模板编辑器检查与调整

日期：2026-10-14。

发现并修复：Vue 响应式对象克隆失败、父子同步重复重置选中项、缩放只改变纸张而不改变元素、画布内部属性控件遮挡内容、离开元素时拖动提前停止、图形只显示占位而未进入打印 HTML、文本无宽度时不可见。

编辑器提供六种元素：二维码、条码、文本、动态字段、日期、流水号。左侧管理元素与图层，中央提供统一毫米坐标画布和示例数据，右侧编辑内容、位置、大小、字体、日期格式和流水号前后缀。支持对齐、复制、上下层、删除、撤销/重做、方向键 0.1mm 微调与 Shift + 方向键 1mm 移动。

日期与每日编号规则见 `specs/001-printer-management-system/contracts/template-rendering.md` 第 7 节。数据库迁移 `0003` 只新增计数和码快照表，已应用到当前连接数据库。

验证包括前后端结构校验、两端图形/日期/流水号渲染测试、真实 MySQL 独立测试库的并发取号、午夜日期边界、每日从 1 计数、补打快照和失败重试；浏览器覆盖属性编辑、保存内容、旧模板切换、图层撤销、不同缩放下拖动 10mm、键盘微调及窄屏排版。

打印端生成的标签 HTML 已生成 PDF 检查图形与页面尺寸（60×40mm）。本轮没有操作物理打印机，驱动纸张设置与实际出纸误差仍需要工位设备验证。
