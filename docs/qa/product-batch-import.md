# 产品批号表导入

管理后台选择所属产品并上传一个 `.xlsx`。首行按列名识别“防伪码”和“产品批号”，允许调换列顺序；“状态”可选，仅为外部查询信息，不设置本系统打印状态。

每行产品批号存到码表，合格证第二行优先读取逐码批号。分配单生产批号仅为旧码的备用值。已导入批号的码可直接分配，无需重复填写。历史码和导入批次通过可空新增列兼容，旧版双文件 API 仍可用。

防伪码必须为100位以内字母数字，产品批号必填且不超过64字符。超过15位的数字防伪码须存为文本；公式单元格拒绝。重复码遵循现有整批拒绝 / 跳过策略，错误可下载明细。空白行忽略。

验证覆盖单文件上传、逐码批号、前导零、状态不影响打印、批号优先级、产品有效性、重复码、错误表头、数字精度和公式错误，并回归旧版导入、分配和打印日期流水号。用户提供的样表完成只读解析检查，未创建真实导入批次。
