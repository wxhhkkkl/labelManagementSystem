# 蓝白 UI 设计方案

范围：管理后台、工位打印端、管理后台登录页。蓝白主题已应用到项目，交互原型保留供设计参考。

## 配色与组件

| 用途 | 色值 |
| --- | --- |
| 品牌蓝、主要操作、选中项 | `#2563EB` |
| 工作区背景 | `#F4F7FC` |
| 卡片、表单、侧栏 | `#FFFFFF` |
| 浅蓝选中背景 | `#EDF4FF` |
| 主文字 | `#172B4D` |
| 次要文字 | `#687C99` |
| 边框 | `#E4EBF5` |
| 成功文字 | `#138565` |

正文 14px，页面标题 25px，区块标题 16px。间距使用 8/12/16/24/32px；面板圆角 12px，控件圆角 7px。蓝色强调主操作和当前位置，绿、橙、红只用于成功、警告、错误等状态，并同时提供文字提示。

## 管理后台

- 左侧分组导航，顶部显示当前位置、管理员身份与退出操作。
- 工作空间：码量看板。
- 基础管理：组织树、工位管理、账号管理、产品管理、模板管理。
- 码与打印：码导入、码分配、码池、补打与作废、补打作废台账、打印明细、码追溯、操作日志。
- 看板按待分配、已分配未打印、已打印、已作废四种业务口径展示；按公司汇总码量。
- 列表页沿用统一布局：页标题与描述、筛选区、白色表格、分页区。表单的主要操作使用蓝色按钮。
- 原型中的组织与工位、打印记录入口为视觉分组；落地时保留现有独立业务路由。

## 工位打印端

- 顶部显示公司、工位及打印服务状态；导航分为工位打印与工位设置。
- 左侧打印配置：产品、打印机、可打印码数量、扫码定位、打印数量及开始打印。
- 右侧显示本次任务结果与补打任务，失败时显示原因和已有的失败回退操作。
- 工位设置显示服务地址、公司、绑定工位及默认打印机；首次绑定页复用同一表单样式。
- 设计原型的打印按钮只更新示例任务，无真实打印或数据库写入。

## 登录与响应式

- 登录页为蓝色品牌区 + 白色表单区；账号、密码和登录按钮保持清晰的纵向顺序。
- 未登录跳转、登录失败提示与令牌失效处理沿用已实现的认证流程。
- 低于 850px 时统计卡片变为两列；低于 600px 时工位配置和任务纵向排列，登录页上下排列。
- 后台窄屏落地时使用可展开菜单保留全部导航；表格允许局部横向滚动。

## 原型与实际数据

原型以示例公司、产品、工位和码量展示视觉效果。实际项目保持真实空状态，不注入示例数据。后续落地覆盖通用控件的加载、空白、错误、停用和禁用状态。

## 实现与验证

- 公共主题：`shared/ui/theme.css`，供两端复用配色、字体与 Element Plus 控件样式。
- 管理后台采用完整分组侧栏与窄屏菜单；保留全部 14 个现有业务路由。
- 登录页、看板统计卡片、表格、筛选栏、表单和组织树使用统一蓝白样式。
- 工位端采用打印配置与任务结果分栏，首次绑定与工位设置沿用现有业务逻辑。
- 两端启用中文控件文案。
- 验证：两端生产构建、后台 122 项单元测试、工位端 43 项单元测试、3 项登录浏览器测试通过。
- 实际管理员登录、后台菜单导航、工位绑定与打印/设置界面、390px 窄屏布局已检查。工位界面检查使用模拟接口，未执行真实打印。
